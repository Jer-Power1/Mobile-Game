# Arcane Survivor — Store Descriptions

## Short Description

Survive enemy waves, collect XP, and build powerful weapon combinations.

Character count: 74 characters including spaces.

## Long Description

Arcane Survivor is a fast-paced mobile arena-survivor roguelite built around short, increasingly intense runs.

Move through the arena using a one-thumb virtual joystick while your equipped weapons attack automatically. Defeated enemies drop XP, encouraging you to move into danger to collect resources while avoiding increasingly dense groups of enemies.

As you level up, choose upgrades that improve your weapons and passive abilities. Different upgrade choices allow each run to develop into a different build, with the player becoming more powerful as the enemy pressure increases.

Current vertical-slice features include:

- Landscape mobile gameplay.
- One-thumb virtual joystick movement.
- Automatic weapon attacks.
- Three weapon options.
- Passive upgrades.
- XP collection and levelling.
- Randomised upgrade choices.
- Increasing enemy spawn pressure.
- Health, XP, level and run-time HUD.
- Pause and resume support.
- Game-over, restart and main-menu flow.

Arcane Survivor is currently a student project developed for Mobile Game Development. The current build focuses on demonstrating the complete core gameplay loop and Android platform readiness.
