# Arcane Survivor — Data Use and Privacy Statement

**Version:** 0.1.0  
**Platform:** Android  
**Project:** Student development build

## Summary

Arcane Survivor is a student game project. The gameplay code implemented for the current build does not intentionally request the player to create an account or enter personal information.

## Data Used by the Game

The current gameplay implementation uses local runtime information required to play the game, including player input, game state, health, XP, upgrades, run time, pause state and scene state.

This gameplay information is used during the current play session to operate the game.

## Personal Information

The current game design does not include:

- User accounts or login forms.
- Collection of names, email addresses or phone numbers.
- Location-based gameplay.
- Contacts access.
- Camera or microphone gameplay features.
- Advertising systems implemented by the student.
- In-app purchases implemented by the student.
- Social or multiplayer features implemented by the student.

## Network and Third-Party Services

No network-dependent gameplay feature has been intentionally implemented in the Arcane Survivor game code.

Before any public store submission, the final Android package and enabled Unity packages/services must be checked to confirm whether the built application includes any third-party analytics, diagnostics, crash reporting, advertising, or other network-enabled services. The final Google Play Data safety answers must reflect the behaviour of the actual submitted APK/AAB rather than this design document alone.

## Local Storage

The current vertical slice does not intentionally implement player accounts, cloud saves or meta-progression save data. Game progress is run-based and resets when a new run begins.

## Permissions

The final release package should be reviewed before publication to identify Android permissions generated by Unity or any enabled packages. Any permission present in the final application must be assessed against the app's actual behaviour.
